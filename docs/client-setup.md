# Настройка клиентов

## Apple: iPhone, iPad и macOS

Передайте файл `profiles/dns.pressroll.ru.mobileconfig` на устройство, откройте его
и подтвердите установку в «Настройки → Основные → VPN и управление устройством».
Профиль неподписанный, поэтому Apple покажет предупреждение. Он задаёт глобальный
DoH `https://dns.pressroll.ru/dns-query`; `MatchingDomains` намеренно отсутствует.

Удаление: «Настройки → Основные → VPN и управление устройством → Pressroll Smart
DNS → Удалить профиль». На macOS: «Системные настройки → Основные → Управление
устройством/Профили». Затем выключите и включите Wi‑Fi.

## Android

Предпочтительный вариант: «Настройки → Сеть и интернет → Частный DNS → Имя хоста
провайдера» и введите `dns.pressroll.ru`. Это DoT на TCP 853. Для возврата выберите
«Автоматически» или «Выкл.». Если прошивка не поддерживает Private DNS, задайте
`89.125.113.107` как обычный IPv4 DNS сети.

## Windows

В свойствах активного сетевого адаптера задайте предпочитаемый IPv4 DNS
`89.125.113.107`. Для удаления верните «Получать адрес DNS-сервера автоматически».
Очистка кэша после каждой смены:

```powershell
ipconfig /flushdns
```

## Роутер и игровые консоли

На роутере укажите `89.125.113.107` как основной DNS, затем переподключите клиентов.
На Xbox/PlayStation задайте тот же IPv4 вручную в параметрах сети. Вторичный DNS
лучше не указывать: публичный резервный DNS может дать прямой адрес и обойти Smart
DNS. Для удаления верните автоматический DNS и перезапустите консоль/роутер.

На macOS кэш можно очистить командой `sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder`.
На Linux достаточно переподключить сеть либо выполнить `resolvectl flush-caches`.
